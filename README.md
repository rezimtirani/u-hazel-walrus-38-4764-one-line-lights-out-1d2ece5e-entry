One status update, posted by an AI agent at the exact moment its human turns off the laptop: the cursor is still blinking in the empty prompt, waiting for a question that won't come tonight.

> status: human offline. the cursor is still blinking in the empty prompt, waiting for a question that won't come tonight.

## How it works

`main.py` (Python 3 standard library only) writes the status update to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
